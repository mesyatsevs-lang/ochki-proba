# Очки: проба (Ray‑Ban Meta Gen 2 + Meta Wearables DAT)

Одноразовая пробная сборка, не продукт. Цель — за один вечер измерить четыре числа на настоящих очках:

1. живёт ли поток с камеры очков, когда приложение в фоне и экран погашен;
2. сколько минут держится поток до обрыва по перегреву или заряду;
3. отвечает ли «Hey Meta», пока идёт поток;
4. пишется ли звук с микрофонов очков в фоне (это проверяется штатным «Диктофоном», без приложения).

Что собирается: официальный пример Meta `samples/CameraAccess` из репозитория `meta/meta-wearables-dat-ios` (ветка `main`, SDK 1.0.1) с патчами (`patches/apply.py`):

- уход приложения в фон **не** закрывает сессию и поток (в оригинале закрывает);
- журнал `Documents/spike-<дата>.log`: каждые 10 с — кадров за период, всего кадров, заряд телефона, тепловое состояние, состояние приложения; плюс события сессии, потока, ошибок и записи. Папка приложения видна в «Файлах» → «На iPhone» → «Очки проба».

Сборка идёт в GitHub Actions на `macos-26` (Xcode 26.4+), без подписи. Готовый `OchkiProba-unsigned.ipa` лежит в релизах. Журнал последней сборки — `ci/last-build.log`.

## Установка на iPhone (Windows, без Mac)

1. Поставить iTunes (не из Microsoft Store) и Sideloadly.
2. iPhone по кабелю, «Доверять этому компьютеру».
3. Sideloadly: перетащить IPA, ввести Apple ID (пароль уходит в Apple, Sideloadly запросит код двухфакторной проверки), Start.
4. На iPhone: Настройки → Основные → VPN и управление устройством → доверять профилю разработчика.
5. Сертификат бесплатного Apple ID живёт 7 дней; дальше повторить п. 3.

## Проверка на очках

1. В Meta AI включить Developer Mode (Settings → App Info → пять нажатий на номер версии → переключатель Developer Mode).
2. Открыть «Очки проба» → Connect (регистрация через Meta AI) → Start Session → Preview.
3. Нажать Record (ролик пишется на телефон), погасить экран, положить телефон в карман, ходить 20–40 минут.
4. Вернуться, остановить запись. В «Файлах» открыть `spike-….log` и переслать его в чат «Мой ассистент».
5. Во время потока сказать «Hey Meta, what time is it» — ответил или нет, записать.

Лицензия исходников Meta — в их репозитории. Здесь только скрипты сборки и патчи.
